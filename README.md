## Task 5: Tableau Dashboard

Created an interactive Grocery Store Sales Dashboard using Tableau Public to visualize sales performance and transaction patterns.

### Dashboard Features
- **KPI Cards:** Total Sales, Quantity Sold, and Total Transactions.
- **Sales by Product Category:** Compares sales across product categories.
- **Sales by Store Location:** Identifies locations with higher recorded sales.
- **Monthly Sales Trend:** Shows how recorded sales change over time.
- **Transactions by Payment Mode:** Displays the distribution of transactions by payment method.
- **Top 5 Products by Sales:** Highlights the products with the highest recorded sales.

### Tools Used
- Tableau Public
- Microsoft Excel
- GitHub
