# Grocery Store Data Analytics

## Project Overview
This project is part of my VINIX Data Analytics Internship. It covers data collection, data cleaning, and exploratory analysis of a grocery store sales dataset.

## Task 2: Data Collection
- Collected a grocery store sales dataset from Kaggle.
- Stored the dataset in CSV format.
- Reviewed the dataset structure and its columns.

## Task 3: Data Cleaning
- Checked Transaction IDs for duplicate values.
- Inspected missing values in the dataset.
- Reviewed date formats and store location names for consistency.
- Prepared a separate cleaned dataset while preserving the original file.

## Task 4: Data Analysis
Analyzed the grocery sales dataset to identify sales patterns and business insights.

### Analysis Performed
- Total recorded sales and quantity sold.
- Sales by product category.
- Sales by store location.
- Monthly sales trends.
- Sales by payment method.
- Top 15 products by recorded sales.
- Data quality checks and remaining missing values.

### Key Findings
- Total recorded sales: ₹8,47,900.70
- Total quantity sold: 12,665
- Highest-sales category: Frozen Foods
- Highest-sales location: Delhi
- Most frequent payment method: UPI

These findings are calculated from the supplied dataset and represent recorded sales, not profit.

## Project Files
- `grocery_store_data_for_vinix.csv` — original dataset.

## Limitations
Some missing values remain in the source dataset, including Discount_Percent, Total_Sales, and Customer_Rating. These values should be reviewed before using the results for business decisions.

## Conclusion
This project demonstrates the basic data analytics workflow: collecting data, checking and cleaning it, analyzing sales patterns, visualizing findings, and documenting results.
